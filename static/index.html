How this works:

  1. Paste the whole encrypted message, from -----BEGIN PGP MESSAGE----- to -----END PGP MESSAGE-----.
  2. Enter your OpenPGP PIN. The YubiKey recovers the message's session key; this server never decrypts the message.
  3. Save the message as message.asc on your own machine and run one of the commands shown, with gpg or Sequoia (sq). They decrypt it with the session key, without needing your private key.

The session key opens this one message only. Treat it like the message itself.
